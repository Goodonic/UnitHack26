# UnitHack26

**UnitHack26** — это dungeon crawler от первого лица с процедурно генерируемыми подземельями и карточной пошаговой боевой системой. Игроку предстоит пройти несколько этажей опасного подземелья, исследовать комнаты и коридоры, принимать тактические решения в боях и заполучить один из ключей Холидея.

Игра разработана на Unity для платформы **Windows**.

---

## Цель игры

Главная цель — пройти все этажи подземелья и найти один из ключей Холидея.

На каждом этаже игрок начинает со стартовой точки, исследует подземелье и ищет выход. После нахождения выхода открывается путь на следующий этаж. По мере продвижения игрок сталкивается с опасностями и сражается с противниками в пошаговых карточных боях.

---

## Как играть

### Исследование подземелья

Игрок перемещается по подземелью от первого лица. Уровни построены по клеточной системе: каждый шаг перемещает персонажа на одну клетку вперёд или назад, а повороты происходят на 90 градусов.

Используйте мини-карту, чтобы ориентироваться в подземелье, находить проходы, стартовую точку и выход.

### Боевая система

Сражения проходят в пошаговом карточном формате. Во время боя игрок использует карты для атаки, защиты и применения различных эффектов.

Каждый ход требует выбора оптимального действия: атаковать врага, защититься, подготовиться к следующему ходу или использовать особую карту. Победа в боях помогает продвигаться дальше по подземелью.

### Прохождение этажей

Чтобы завершить этаж, нужно найти клетку выхода. После перехода на следующий этаж подземелье обновляется, а игрок продолжает путь к ключу Холидея.

---

## Управление

| Клавиша | Действие |
|---|---|
| `W` | Движение вперёд |
| `S` | Движение назад |
| `A` | Поворот налево |
| `D` | Поворот направо |

---

## Обозначения на мини-карте

Мини-карта показывает структуру текущего этажа и помогает ориентироваться во время исследования.

| Цвет | Значение |
|---|---|
| Чёрный | Стена или закрытая область |
| Серый | Каменный пол |
| Коричневый | Земля |
| Синий | Вода |
| Жёлтый | Стартовая точка |
| Зелёный | Выход |
| Красный | Игрок |

## Советы по прохождению

- Следите за мини-картой: она помогает не заблудиться и быстрее найти выход.
- Запоминайте расположение коридоров и развилок.
- Не спешите переходить на следующий этаж, если хотите полностью изучить текущий.
- В бою заранее продумывайте ход: иногда защита важнее атаки.
- Используйте карты с учётом ситуации и состояния противника.
- Ищите выход на каждом этаже, чтобы приблизиться к ключу Холидея.

## Установка и запуск

### Системные требования

- Операционная система: Windows
- Клавиатура
- Монитор с поддержкой стандартного разрешения экрана

### Запуск игры

1. Скачайте архив или папку с готовым билдом игры.
2. Распакуйте архив в удобное место.
3. Откройте папку с игрой.
4. Запустите файл `UnitHack26.exe`.
5. Начните прохождение подземелья.

## О проекте

**UnitHack26** сочетает исследование процедурного подземелья и тактические карточные сражения. Каждый этаж отличается планировкой, поэтому прохождение требует внимательности, ориентации по карте и продуманного подхода к боям.

Игрок проходит путь через подземелье, этаж за этажом приближаясь к главной награде — одному из ключей Холидея.
